# Hiyuki-Bot

Base inicial del bot WhatsApp con Baileys.

## Comandos base
- `.menu`
- `.update`
- `.setapi base <url>`
- `.setapi key <apikey>`
- `.play <nombre cancion>`

## Inicio rapido
1. `npm install`
2. `npm start`
3. Al primer inicio, escribe tu numero para vincular.
4. El bot crea `settings.json` automaticamente (sin `.env`).
5. Configura tu API:
   - `.setapi base https://tu-api.com`
   - `.setapi key TU_API_KEY`
